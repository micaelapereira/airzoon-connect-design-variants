airzoonconnect.com · page for already-connected users

Six design variants of the page served at airzoonconnect.com when a user who is already connected opens the address again (MFI-CONNECT-0001). Same approved copy in FR / ES / EN, one screen with no scrolling, mobile first. Each page is a single self-contained HTML file: the logo is an inline SVG, no images.

Variants A, B and C place the airZoon logo right above the title. Variants D, E and F keep the logo at the top and add a Wi-Fi icon above the title. Each pair shares the same colours: A and D follow the brand charter in the brief (dark charcoal with orange halo), B and E are a light alternative, and C and F use airZoon red as the accent on the dark background.

Demo only: fonts (Poppins, Inter) load from Google Fonts. In production they should be self-hosted, or fall back to system fonts, to keep the page free of external resources. The footer link is a placeholder until the b.link tracking link is created.
